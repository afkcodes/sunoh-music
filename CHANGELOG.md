# Changelog

All notable changes to this project will be documented in this file.

## [v1.0.0] - Initial Release

### ✨ Features
- **Player & Queue**: Implemented premium player sheet, queue management, and drag-and-drop sortable items.
- **Auto-Queue & Radio**: Added radio playback with infinite regional playback (auto-pagination, language propagation) and smart recommendations.
- **Equalizer**: Features an integrated equalizer interface with adjustable bands and built-in presets.
- **Homescreen**: Implemented home screen data loading, premium recently played section, and Saavn channels/occasions integration.
- **Search Engine**: Added a redesigned search screen featuring trending suggestions, occasions, and full media search.
- **Library & Playlists**: Browse albums, playlists, songs, artists, and handle large scrollable lists utilizing high-performance components.
- **Analytics**: Intergrated `react-native-firebase` analytics for usage tracking, leveraging the latest Firebase v22 modular SDK.
- **UX Improvements**: Premium theming based on dynamic colors, unified circular cards, custom font sets, and Telegram community links.

### 🛠️ Build & Configuration
- **APK Optimization**: Enabled APK splitting per architecture (x86, x86_64, arm64-v8a, armeabi-v7a) via Gradle configuration.
- **Keystore Signing**: Generated release signing keys and configured the production signing profile for secure standalone releases.
- **Gradle Performance**: Increased JVM MaxMetaspaceSize limits to resolve Android out-of-memory build failures.

### 🐛 Bug Fixes
- **Navigation Crashes**: Prevented `Cannot add the same handler more than once` errors during Fast Refresh and isolated navigator handlers.
- **Audio Context**: Fixed stale radio context being wiped on initial play and resolved timing issues during restoration to prevent race conditions.
- **Autoplay Handling**: Established a proper auto-play fix, position persistence handling across app reloads, and time formatting adjustments.
- **Media Mapping**: Resolved TypeErrors in the `dataExtractor` and patched radio configurations for better cross-provider rendering mapping.
